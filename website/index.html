Enkripsi di perangkat
Argon2id untuk derivasi kunci. XChaCha20-Poly1305 untuk enkripsi vault.
Kunci dengan caramu
Master password, auto-lock saat idle, dan opsi quick-unlock Windows Hello.
Backup tetap milikmu
Backup otomatis .vault.bak serta ekspor dan restore file terenkripsi. Simpan salinan di tempat aman.

Sebelum mulai.

Apakah Velo butuh internet?

Menyimpan, mencari, dan membuka vault berjalan lokal tanpa internet. Internet diperlukan untuk mengunduh installer dan komponen Windows bila belum tersedia.

Bagaimana cara install?

Download Velo-Setup.exe dari GitHub Release, jalankan installer, lalu buat vault dengan master password. Installer belum ditandatangani digital; Windows mungkin menampilkan peringatan SmartScreen. Periksa sumber unduhan dan checksum di halaman rilis.

Kalau lupa master password?

Tidak ada reset password melalui server. Simpan master password dengan aman dan buat backup terenkripsi. Windows Hello adalah opsi quick-unlock, bukan pengganti cadangan master password.

Bisa dipakai di Mac atau Linux?

Rilis ini untuk Windows x64. Installer Mac dan Linux belum tersedia.
