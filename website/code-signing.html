Code signing policy

Current status: SignPath setup prepared; enrollment and approval are pending. The published v0.2.1 installer is unsigned. We do not yet claim a SignPath certificate or sponsorship. Check each release's signing status before downloading.

Signing provider

We intend to apply for the SignPath Foundation open-source program. Once approved and activated, the attribution will be: “Free code signing provided by SignPath.io, certificate by SignPath Foundation”.

People and approvals

Farhan Fathurrohman (@farhanfath) is the project maintainer, committer, reviewer, and signing approver. External contributions require maintainer review. Signing requires the maintainer's manual approval in SignPath; project access must use multi-factor authentication.

Build and verification

Release binaries are built from this project's source on GitHub-hosted Windows runners. When enabled, the pipeline signs the Velo application before packaging, then signs the Windows installer. It verifies Authenticode trust, the approved certificate thumbprint, and a signing timestamp before publishing a checksum. Signing failure stops publication; there is no unsigned fallback in signing mode.

The NSIS uninstaller is not separately signed by this pipeline. Additional signing coverage is subject to SignPath onboarding review. A valid signature identifies the publisher and protects integrity; SmartScreen warnings can still occur while reputation builds.

Privacy policy

Velo stores vault contents on your device. It has no Velo server, telemetry, or account registration. This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The Windows installer may download Microsoft WebView2 if needed. Windows Hello uses Windows services. The website loads fonts from Google Fonts; visits and downloads are served by Vercel and GitHub under their respective privacy policies. Credentials are never entered on this website.
